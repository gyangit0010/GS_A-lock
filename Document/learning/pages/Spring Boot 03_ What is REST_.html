What is REST?

How the React frontend and Spring Boot backend of GA_A-lock will actually talk to each other.

1. API → REST API

API

A way for one piece of software to talk to another. Like a waiter between customer and kitchen: the frontend never touches the database directly, it goes through the backend API.

REST

Representational State Transfer — an architectural style for designing APIs that communicate over HTTP. Not a language, not a Spring feature.

Frontend  →  HTTP Request  →  Spring Boot Backend  →  PostgreSQL

POST /api/auth/register is the frontend telling the backend: "Create a new user."

6. REST is stateless

Each request must carry everything the server needs — the server keeps no memory of the last request.

This is exactly why a JWT is attached to every request via Authorization: Bearer <JWT>, rather than the server remembering you logged in earlier.

Glossary

API
A way for software to communicate with other software.
REST
An architectural style for designing APIs over HTTP, built around resources.
Resource
Something the API works with, e.g. a user, represented by a URL.
JSON
JavaScript Object Notation — the structured format APIs commonly exchange.
Stateless
Each request carries what the server needs; no session memory between requests.
Status code
A number in the response telling the client what happened (200, 401, 404...).
