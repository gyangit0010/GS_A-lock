The Big Idea: Bridging Java and Databases

Java uses objects, while databases use relational tables. ORM bridges this gap.

Java Objects↕ORM (Hibernate)↕Database Tables (PostgreSQL)

Instead of writing raw JDBC SQL boilerplate for everything, ORM allows you to manipulate Java objects while frameworks like Hibernate handle translating those actions into SQL queries automatically.

Glossary

ORM (Object-Relational Mapping)
A technique that connects rich Java objects to relational database tables.
JPA (Java Persistence API)
A specification/set of rules defining how Java objects should be persisted in relational databases.
Hibernate
The most popular open-source JPA implementation framework that executes the actual ORM work.
Spring Data JPA
A Spring framework abstraction layer that simplifies building repository interfaces over JPA.
Entity
A Java class annotated with @Entity representing data stored in a table row.
