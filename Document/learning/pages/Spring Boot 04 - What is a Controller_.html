The Big Idea: Controller as the API Entry Point

Where does a REST request actually enter our Spring Boot application? Through the Controller layer.

HTTP Request+@RestController+@RequestMapping=REST Entry Point

A Controller is a Spring component responsible for handling incoming HTTP requests from clients (like our React frontend) and returning structured HTTP responses (usually JSON).

React Frontend ──(POST /api/auth/login)──> [ AuthController ] ──> [ AuthService ]

Controller → Service Architecture Separation

Controllers must only handle HTTP routing and delegate business logic to the Service layer.

What Controllers Should Do
  • Receive incoming HTTP requests
  • Extract path/query/body variables
  • Invoke Service methods
  • Return ResponseEntity & JSON
What Controllers Should NOT Do
  • Write complex business algorithms
  • Talk directly to the Database Repository
  • Handle raw password hashing / DB transactions
  • Generate JWT tokens inline

Glossary

Controller
The HTTP/API entry point layer that receives client requests and returns responses.
@RestController
Combines @Controller and @ResponseBody for building JSON REST APIs.
DTO (Data Transfer Object)
A plain Java object used to receive and encapsulate incoming request body payloads.
@RequestBody
Instructs Spring to deserialize incoming JSON payloads into Java DTO objects automatically.
ResponseEntity
Provides precise programmatic control over HTTP status codes (200, 201, 400, etc.).
