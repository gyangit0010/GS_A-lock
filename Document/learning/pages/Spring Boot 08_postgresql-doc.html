The Big Idea: Persistent Storage

Without a database, all user registration data disappears when the application stops. PostgreSQL provides persistent storage.

Spring Boot App↕Hibernate / JPA↕PostgreSQL (Tables)

PostgreSQL is a powerful open-source Relational Database Management System (RDBMS). It organizes structured data into tables consisting of rows and columns, allowing secure and reliable persistence for user credentials and application records.

Glossary

PostgreSQL
An advanced open-source relational database management system (RDBMS).
RDBMS
Relational Database Management System software structured around relational tables.
CRUD
Create, Read, Update, Delete — the four fundamental data operations.
Primary Key
A unique identifier column for each row in a table.
Foreign Key
A column that links/references a primary key in another table to establish relationships.
Transaction
A grouped unit of database work that either fully commits or entirely rolls back.
