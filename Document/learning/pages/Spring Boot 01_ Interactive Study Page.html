The big idea

Spring Boot is a Java framework for building production-ready apps fast, with less configuration.

Spring Framework+Sensible defaults+Auto-configuration+Embedded server+Easy setup=Spring Boot

Before Boot you hand-configured the server, database connection, component scanning, MVC and security. Now you declare what you need and write real logic, like this:

@RestController
public class AuthController {
    @PostMapping("/register")
    public String register() {
        return "User registered successfully";
    }
}

Spring Framework vs Spring Boot

Boot sits on top of Spring. You still use Spring underneath.

Spring Framework

The core ecosystem: Dependency Injection, Inversion of Control, web, database integration, security, transactions, testing.

Spring Boot

Makes Spring easy: auto-configuration, starter dependencies, embedded servers, convention over configuration, production-ready features.

Mental model: Spring provides the core functionality → Boot makes it easier to use → your application.

What happens when the app starts?

You run mvn spring-boot:run. Step through it.

@SpringBootApplication   // = @SpringBootConfiguration
public class AuthApplication {   //   + @EnableAutoConfiguration
    public static void main(String[] args) {   //   + @ComponentScan
        SpringApplication.run(AuthApplication.class, args);
    }
}
Don't memorize the three inner annotations yet. Just remember: @SpringBootApplication is the main entry point and configuration annotation.

Glossary

Spring Boot
Framework for quickly building Spring-based Java applications.
Starter
A dependency bundle giving you the libraries for one feature.
Auto-Configuration
Boot configures parts of the app based on your dependencies and settings.
Embedded Server
A web server (commonly Tomcat) packaged inside your app.
@SpringBootApplication
Main annotation on the entry-point class.
Application Context
The Spring container managing beans and their relationships (more in Doc 02).
